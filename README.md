# Digital Visit Card Backend

**Front Project Link:**
https://github.com/mrsedghi/digitalVisitCart


A modern digital business card solution built with Vite, React, MUI, and Swiper. Generate beautiful digital cards with QR codes and store them in a MySQL database.

[![React](https://img.shields.io/badge/React-18.2-blue?logo=react)](https://reactjs.org/)
[![Vite](https://img.shields.io/badge/Vite-4.0-orange?logo=vite)](https://vitejs.dev/)
[![MUI](https://img.shields.io/badge/MUI-5.0-blue?logo=mui)](https://mui.com/)
[![Swiper](https://img.shields.io/badge/Swiper-9.0-blue?logo=swiper)](https://swiperjs.com/)
[![MySQL](https://img.shields.io/badge/MySQL-8.0-blue?logo=mysql)](https://www.mysql.com/)

## ✨ Features

- 🖥️ Modern responsive UI with Material-UI components
- 🎚️ Interactive card editor with live preview
- 📲 QR code generation for easy sharing
- 💾 Data persistence with MySQL backend
- 🔄 Smooth animations with Swiper.js
- ⚡ Blazing fast performance with Vite



### Installation

1. **Clone both repositories:**

```bash
git clone https://github.com/mrsedghi/digitalVisitCart.git
git clone https://github.com/mrsedghi/digitalVisitCartbackend.git
```

2. **Frontend Setup:**
   
```bash
cd digitalVisitCart
npm install
npm run dev
```

3. **Backend Setup:**
   
```bash
cd digitalVisitCartbackend
npm install
# Configure your .env file with database credentials
npm run dev
```

### 🛠️ Configuration
Edit a db.config.js file and Create a .env file in the backend directory with these variables:
```bash
PORT="8081"
DB_HOST="localhost"
DB_USER="your_username"
DB_PASSWORD="your_password"
DB_DATABASE="digitalcards"
```
